# Canonical fixtures

`business_scenarios.json` names stable IDs for the canonical guest-service scenarios.
`hotel_data_schema.json` records the generated CSV contract, status values, date
range, fixed 2026-11-08 reference date, and masked-payment restriction. The reviewed
2026-09-01 chronology is shifted as a unit by 68 days. Maria Garcia's two-room
`RES-FAMILY-2026` stay at `HTL-004` is November 17–19, with dining November 18.
Generated data itself remains ignored under `data/generated/`.
